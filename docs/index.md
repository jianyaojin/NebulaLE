# Welcome to NebulaLE

NebulaLE (Nebula Low Energy) is a continuation of the Nebula simulator of electron-matter interaction, with specific focus on improving the simulator 
and its physics models to work better at low electron energies (< 100 eV).

The original Nebula simulator can be found on [github](https://github.com/nebula-simulator), and its documentation is 
[here](https://nebula-simulator.github.io/). The basic functionality of the simulator has been explained there and will not be repeated here.

The main repository for NebulaLE can be found at: [NebulaLE](https://github.com/jianyaojin/NebulaLE/tree/master)

The associated repository for cstoolLE is: [cstoolLE](https://github.com/jianyaojin/cstoolLE).
