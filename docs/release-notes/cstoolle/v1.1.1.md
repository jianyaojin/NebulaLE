# CstoolLE version 1.1.1

pkg_resources was long deprecated, so the dependency was removed and replaced with a new one. This package was only used to identify and download 
the relevant endf files for ionization cross sections.

New implementation basically follows the [migration guide](https://importlib-resources.readthedocs.io/en/latest/migration.html#pkg-resources-resource-filename)
exactly.

Note that endf files are saved not in cstool/data/endf_data, but where your virtual environment / python installation lives. This is because python
treats the endf files as resources for the cstool package.
