# CstoolLE version 1.1.0

## Added minimum excitation to .mat file

The minimum excitation for metals is the Fermi level from the bottom of the valence band and for insulators and semiconductors it is the valence
band width plus the band gap.

We need this quantity in Nebula because the omega axis for the q_2dicdf (in other words the q icdf table) output from cstool is written between
the lowest optical excitation energy (~0.01 eV) and $E-E_{\min}$ where $E_{\min}$ is the minimum excitation energy. However, since the omega axis 
has no scale output in cstool, Nebula reads it as a 0 to 1 scale, which changes the energy zero point from the valence band to the minimum excitation
level, which is not the same energy reference as the rest of the simulator. 

In short, $E_\min$ is outputted here to be used in Nebula to read the table using $\frac{\omega}{E-E\min}$ instead of $\frac{\omega}{E}$


## Separated phonon and Mott scattering

Mott and phonon scattering cross sections are usually merged using the Kieft and Bosch approach. This has been removed and the two models are 
separated and outputted. There is also functionality to write the pdf and cdfs to the .mat file if desired, but to save space it is disabled.

Note that because the old Kieft model is not written to .mat file by default now, this version of the .mat file requires NebulaLE version 1.1.0 
or higher to run. One can of course change the separate bool to false in cstool.py to overcome this.
