# NebulaLE version 1.1.1

## Fixed trajectories bug

Nebula trajectories version was not outputting the correct number of inelastic events (It was omitting the non SE generating events), and also not separating elastic and quasi elastic scattering events. This bug has since been fixed and tested, the number of outputted events of all scattering types matches with the number generated during simulation.

## Elastic Quasielastic crossover energy changed

To better match yields data for gold, the crossover energy has been changed from 100 eV to 15 eV. This improves gold yields match at low energies below 100 eV, but hurts the match at higher energies above 1 keV. Why this is is not yet clear.
