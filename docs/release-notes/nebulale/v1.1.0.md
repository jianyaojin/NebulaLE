# NebulaLE version 1.1.0

## Fixed q reading off energy reference mismatch.

The output omega axis for the q tables should run from the minimum optical excitation to $E-E_{\min}$, where $E_\min$ the minimum excitation energy.
However, the table is outputted with no scale from cstool and so is read in Nebula as a 0 to 1 scale, thus changing the energy zero point from the
valence band minimum to the minimum excitation level, which causes a misreading and q values to be sampled incorrectly. We change this reference in 
full_penn.h from $\frac{\omega}{E}$ to $\frac{\omega}{E-E\min}$.


## Separated phonon and Mott scattering

While Kieft and Bosch introduced the hybrid model which interpolates between phonon scattering and Mott scattering, we argue that the two are distinct
scattering channels that are independent of each other and so should be selected between following Mathiessen's rule. 

Requires a .mat file from cstool version 1.1.0 or later to run.
